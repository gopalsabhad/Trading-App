# Trading-App
TradePro — A demo paper-trading platform with live charts, AI buy/hold/sell signals, sentiment analysis, and portfolio tracking. Built with React, TypeScript, and Vite.

# Extended Description
TradePro is a fully functional demo trading platform inspired by TradingView, Webull, and professional broker terminals. Practice trading with $100,000 in paper money using real-time or simulated market data, candlestick charts, order books, and a full order entry workflow.

The app includes an AI Trade Advisor that generates buy, hold, and sell signals using technical analysis (RSI, MACD, moving averages, volume) combined with news sentiment. Use the Signal Finder to screen stocks by action and confidence level, set push or email alerts on strong signals, and manage positions with unrealized P&L tracking.

Optional integrations with Finnhub and Alpha Vantage enable live quotes, symbol search across US & TSX markets, and real news sentiment. Without API keys, the app runs entirely on simulated data for demos and learning.
